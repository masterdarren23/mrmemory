Introduction

Stateless AI models are stuck in the past. They can't retain context during conversations, leading to frustrating user experiences and reduced agent capabilities. But what if you could create an AI that learns from its mistakes and adapts over time?

Let's take a look at how to build a memory-powered API using MrMemory and FastAPI.

Building a Memory-Enabled Agent

To create an agent that can perceive, decide, act, and remember, you need to treat memory as a first-class citizen in your system architecture. A modular design allows you to evolve individual components independently, ensuring a scalable solution.

MrMemory makes it easy to integrate memory into FastAPI:


from mrmemory import MrMemory

client = MrMemory(api_key="your-key")
client.remember("user prefers dark mode", tags=["preferences"])

This code snippet shows how to store a user preference in MrMemory using the remember method. The tags parameter allows for efficient recall of related memories.

Semantic Embeddings for Smarter Recall

Semantic embeddings are key to unlocking smarter recall capabilities. By representing memories as dense vectors, you can leverage vector-based search and retrieval algorithms.

MrMemory's API provides a simple interface for working with semantic embeddings:


results = client.recall("what theme does the user like?")

This example shows how to retrieve related memories using the recall method. The results will be returned as a list of tuples containing the memory and its associated tags.

FastAPI Integration

To integrate MrMemory into your FastAPI application, use this code:


from fastapi import FastAPI
from mrmemory import MrMemory

app = FastAPI()
client = MrMemory(api_key="your-key")

@app.get("/remember")
def remember():
    client.remember("user prefers dark mode", tags=["preferences"])
    return {"message": "Memory stored successfully"}

@app.get("/recall")
def recall():
    results = client.recall("what theme does the user like?")
    return {"results": results}

This example demonstrates how to create API endpoints for storing and retrieving memories using MrMemory's API.
