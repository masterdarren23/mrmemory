OpenAI Agents SDK Amnesia: How to Keep Your Chatbot's Memory

I've lost count of how many times I've built a chatbot, only to have it forget everything when I restart the process. You're not alone. OpenAI Agents SDK's lack of persistent memory can be frustrating, especially when you're dealing with token costs, context windows, and truncated history.

Let's take a look at how to add memory to your OpenAI Agents SDK using MrMemory, a managed memory API that makes it easy to add recall to your chatbot.

Installing MrMemory

First, install MrMemory using pip:


pip install mrmemory

Next, import the MrMemory client and initialize it with your API key:


from mrmemory import MrMemory
client = MrMemory(api_key="your-key")

Using MrMemory

Now you can use the remember() method to store memories:


client.remember("user prefers dark mode", tags=["preferences"])

And the recall() method to retrieve relevant memories:


results = client.recall("what theme does the user like?")

MrMemory's compression feature can save up to 60% of token usage, making it easier to store more memories without incurring additional costs.

Comparing Alternatives

You might be wondering about other options. Mem0 is a memory layer API, but lacks compression and self-edit tools. Zep and MemGPT are self-host only, which can be a pain to set up and manage.

Conclusion

Adding memory to your OpenAI Agents SDK is easier than you think. With MrMemory, you can improve your AI's recall in just 5 minutes. Try MrMemory today and see the difference for yourself.
