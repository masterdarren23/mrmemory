Adding Long-Term Memory to CrewAI Agents: Step-by-Step

Meta Description: Learn how to integrate long-term memory into your CrewAI agents for persistent, shared memory. Step-by-step guide with code examples and alternatives.

---

The Problem with Repeat Conversations

Have you ever deployed a CrewAI agent only to have it forget previous conversations and repeat tasks? Or maybe it's making incorrect decisions because it can't recall relevant context? You're not alone. Long-term memory is a crucial aspect of building intelligent AI systems. Without it, your agents are little more than script-kiddies with a bad memory.

Step 1: Enabling Long-Term Memory in CrewAI

To enable long-term memory in CrewAI, initialize your agents with long_term_memory set to True in the memory_config dictionary. Here's an example:


from crewai import Crew

crew = Crew(memory_config={'long_term_memory': True})

Step 2: Using MrMemory for Persistent Storage

MrMemory is a managed memory API that stores and retrieves memories efficiently. You can use it to persist memories across sessions and retrieve them when needed; here's an example:


from mrmemory import MrMemory

client = MrMemory(api_key="your-key")
client.remember("user prefers dark mode", tags=["preferences"])
results = client.recall("what theme does the user like?")

Step 3: Differentiating between Short-Term and Long-Term Memory

In CrewAI, you can reset specific memories individually or delete all memories using the reset_memories function. For example:


from crewai import Memory

memory = Memory()
memory.reset_memories(['short_term_memory'])

Comparison and Alternatives

While MrMemory provides a simple and efficient way to implement long-term memory in CrewAI, consider other alternatives:

  • Mem0: A more complex and customizable memory system.
  • Zep: A self-hosted memory layer for AI agents that's flexible and scalable.
  • MemGPT: A memory layer that's advanced and context-aware.

Conclusion

Adding long-term memory to your CrewAI agents is a game-changer. By following these steps, you can implement long-term memory using MrMemory — try it out and see the benefits of persistent, shared memory for yourself.
