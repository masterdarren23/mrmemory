The Frustrating Reality of CrewAI Agents

You've spent hours crafting a script, only to have your CrewAI agents forget crucial context and interactions every time the script finishes. It's a common pain point, but one that's easy to fix with the right tools.

Introducing MrMemory

MrMemory's API provides a simple and efficient way to add persistent memory to your CrewAI crew. With a single line of code, you can store and retrieve information from a shared memory instance, allowing your agents to recall past interactions and learn from task history.


from mrmemory import MrMemory

client = MrMemory(api_key="your-key")
client.remember("user prefers dark mode", tags=["preferences"])
results = client.recall("what theme does the user like?")

What Makes MrMemory Different?

Other solutions like Mem0, Zep, and MemGPT offer some similar functionality, but they lack features like compression, self-edit, and governance. MrMemory's API is specifically designed to meet the needs of developers like you, with a unique combination of features that make it an attractive choice.

Adding Persistent Memory to CrewAI in 5 Easy Steps

  1. Install MrMemory using pip: pip install mrmemory
  2. Import the MrMemory library and create a client instance: from mrmemory import MrMemory; client = MrMemory(api_key="your-key")
  3. Create a shared memory instance for your entire crew: client.create_memory_instance("crew_memory")
  4. Use the remember method to store information in the shared memory instance: client.remember("user prefers dark mode", tags=["preferences"])
  5. Use the recall method to retrieve information from the shared memory instance: results = client.recall("what theme does the user like?")
