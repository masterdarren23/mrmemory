The Problem with In-Memory Agents

CrewAI agents are powerful tools for automating tasks and workflows. But when they don't retain any information between runs, it's like starting from scratch every time. That makes it tough to create personalized experiences based on user history. Take Sarah, a marketing manager who uses CrewAI to automate lead generation. Without persistent memory, the agent forgets her past interactions with each new run, leading to inconsistent results and a frustrating experience.

Setting Up CrewAI with Persistent Memory

To fix this problem, you'll need to install the necessary libraries using pip:


pip install crewai mrmemory

Next, import the required modules and set up configurations:


from mrmemory import MrMemory
from crewai import Agent, Task, Crew

# Initialize MrMemory client
client = MrMemory(api_key="your-key")

Now, let's create a shared memory instance for your entire crew using MrMemory's remember method:


def store_user_preferences(user_id: str, conversation: list):
"""Store user preferences from conversation history"""
client.remember("user prefers dark mode", tags=["preferences"])

Integrating MrMemory with CrewAI

To integrate MrMemory with your CrewAI agent, you'll need to inject user context into the agent's backstory. Here's an example of how to do this:


def build_context(user_id: str, query: str) -> str:
"""Fetch user profile and relevant memories."""
result = client.recall(query)
return f"User Profile: {result['profile']}\nCurrent Context: {result['context']}\nRelevant History: {result['history']}"

def create_agent_with_memory(user_id: str, role: str, goal: str, query: str) -> Agent:
"""Create an agent with user context baked into backstory"""
# Inject user context into agent's backstory
backstory = build_context(user_id, query)
return Agent(role=role, goal=goal, backstory=backstory)

Comparison and Alternatives

While MrMemory is a powerful solution for persistent memory, there are other alternatives available. Mem0 stores user preferences and past interactions, but it lacks some advanced features of MrMemory. Zep is a self-hosted memory API that requires manual setup and maintenance. MemGPT is a commercial memory API with limited free tier options.

Conclusion

Persistent memory is essential for any CrewAI agent looking to provide personalized experiences. By integrating MrMemory into your project, you can easily store and retrieve user preferences and past interactions.
