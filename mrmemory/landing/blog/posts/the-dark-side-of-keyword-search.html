I still remember the day our AI agent, designed to manage employee onboarding, failed to find the relevant policy document because the search query was too specific. It was a simple case of keyword search vs semantic search. Our agent had indexed the document, but the query was so narrow that it missed the obvious match.

The Problem with Keyword Search

Keyword search is like searching for a needle in a haystack – it's a brute force approach that relies on exact matches. When you search for "project deadline extension," a keyword system looks for documents containing those exact words. But what if the relevant document says "staff retention strategies" instead? You get zero results or irrelevant ones.


from mrmemory import MrMemory
client = MrMemory(api_key="your-key")
client.remember("user prefers dark mode", tags=["preferences"])
results = client.recall("what theme does the user like?")
print(results) # Output: ["dark mode"]

MrMemory uses semantic search under the hood, which enables meaning-based recall. But traditional keyword search still has its uses – like searching for exact phrases or when dealing with highly structured data.

The Power of Semantic Search

Semantic search, on the other hand, uses vector embeddings to represent meaning numerically. This allows the system to find conceptually similar content regardless of exact phrasing. For example, if a user says "I'm stressed about money" in one session and "worried about finances" weeks later, a semantic search system can map both phrases to the same concept.


client = MrMemory(api_key="your-key")
client.remember("user is stressed about money", tags=["financial stress"])
results = client.recall("what's worrying the user?")
print(results) # Output: ["financial stress"]

Comparing the Alternatives

While MrMemory uses semantic search under the hood, other solutions like Mem0 and Zep offer similar functionality. However, Mem0 lacks compression and self-edit tools, while Zep is self-host only. MemGPT, another popular solution, uses semantic search but has limited scalability.

Conclusion

Choosing the right search approach for your AI agent depends on your specific use case and data. While keyword search can be useful in certain situations, semantic search offers more flexibility and accuracy. By using vector databases and semantic search, you can build AI agents that recall information accurately and efficiently.
